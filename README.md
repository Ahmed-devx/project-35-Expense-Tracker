 
# 💰 Expense Tracker

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE) [![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5\&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/HTML) [![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3\&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/CSS) [![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript\&logoColor=black)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

A **simple and responsive Expense Tracker** web application to help you monitor your income and expenses, track transactions, and manage your balance easily.

---

## 🌐 Live Demo

Check out the live project here:
[💻 Expense Tracker Demo](https://ahmed-devx.github.io/project-35-Expense-Tracker/)

---

## 🛠 Features

* **Add Transactions** – Easily log income or expenses with description and amount.
* **Delete Transactions** – Remove any unwanted transactions instantly.
* **Dynamic Balance** – See your total balance, income, and expenses update in real-time.
* **Responsive Design** – Works on desktop, tablet, and mobile devices.
* **Lightweight & Fast** – Pure HTML, CSS, and Vanilla JavaScript, no frameworks required.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/ahmed-devx/project-35-Expense-Tracker.git
cd project-35-Expense-Tracker
```

### Open in Browser

Simply open the `index.html` file in your favorite browser.
